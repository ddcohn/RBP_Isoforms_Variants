# Column dictionary

What every column means in each table in `results/tables/`. Generated by `src/06_column_dictionary.py`, which fails if a table has a column without an entry here, so this file stays in step with the data. Machine-readable copy: `results/tables/column_dictionary.tsv`.

Conventions: percentages are 0-100, fractions are 0-1, empty cells mean not applicable or no data. Genome build GRCh38; Ensembl release 116; UCSC hg38 alignments.

## `rbp_conservation_scores.tsv`

Main table, one row per input RBP (2,335 rows). 93 columns.

### Identity and transcript mapping

| Column | Meaning |
|---|---|
| `GeneSymbol` | Gene symbol as given in the input RBP list. |
| `UniProtID` | UniProt accession as given in the input RBP list. |
| `input_length` | Protein length in amino acids from the input list (`Length`, the UniProt sequence). |
| `match_type` | How the row was linked to Ensembl: `uniprot` = a protein-coding transcript carries this UniProt accession in Ensembl BioMart; `symbol` = no such transcript, so linked by gene symbol; `none` = not linked (every score column is then empty). |
| `ensembl_gene_id` | Ensembl gene ID (release 116) of the selected transcript. |
| `ensembl_transcript_id` | Ensembl transcript ID whose CDS was scored (version suffix omitted). |
| `ensembl_symbol` | Gene name Ensembl uses for the selected gene (may differ from `GeneSymbol` for renamed genes). |
| `chrom` | GRCh38 chromosome of the selected transcript, `chr`-prefixed. |
| `cds_length_nt` | Coding-sequence length of the selected transcript in nucleotides, including the stop codon (from BioMart). |
| `selection_rule` | Which flag the selected transcript carries: `MANE_Select`, `Ensembl_canonical`, or `longest_CDS` (neither flag; longest CDS among the candidates). An exact protein-length match to the input is applied first, so this describes the transcript chosen, not why it won. |
| `n_candidate_transcripts` | Number of transcripts considered for this RBP (after any widening, see `expanded_search`). |
| `expanded_search` | True if no initial candidate had the input protein length and the search was widened to all coding transcripts of the gene plus the UniProt-cross-referenced Ensembl transcripts, which produced an exact-length match. False otherwise. |
| `symbol_agrees` | True if `GeneSymbol` equals `ensembl_symbol`. |
| `cds_aa` | Length in amino acids of the protein encoded by the selected transcript (`cds_length_nt / 3 - 1`). |
| `length_matches_input` | True if `cds_aa` equals `input_length`, i.e. the scored CDS encodes a protein of the same length as the input sequence. False for unmapped rows and for 28 mapped RBPs with no exact-length transcript in Ensembl 116. |
| `input_residues_in_scored_protein` | Fraction of the input protein's residues found, in order, in the scored protein (difflib matching blocks; a coverage measure, not an alignment identity). 1.0 for every exact-length match; for the 28 mismatches it ranges from 0.38 to 1.0 (1.0 means the scored isoform contains the whole input sequence and is longer). Empty for unmapped rows. |

### CDS conservation (UCSC hg38 bigWigs)

| Column | Meaning |
|---|---|

| `phyloP100way_median` | Median phyloP (100 vertebrates) over the same CDS bases. |
| `phyloP100way_frac_conserved` | Fraction of covered CDS bases with phyloP >= 2 (0-1). |

| `phastCons100way_mean` | Mean phastCons (100 vertebrates) over all CDS bases of the selected transcript (all exons pooled, so exons are length-weighted; bases without alignment data are excluded, not zero-filled). phastCons is a per-base conservation probability from 0 to 1. |

| `phastCons100way_frac_conserved` | Fraction of covered CDS bases with phastCons >= 0.9 (0-1). |

## `rbp_conservation_simple.tsv`

Short version of the main table: one headline conservation score per RBP, with a reliability flag (built by `src/07_simple_table.py`). 10 columns.

| Column | Meaning |
|---|---|
| `GeneSymbol` | Gene symbol from the input list. |
| `UniProtID` | UniProt accession from the input list. |
| `cds_phyloP_100way` | Headline score: mean phyloP over the CDS of the selected transcript, 100-vertebrate alignment (= `phyloP100way_mean` in the main table). Roughly -0.6 to 6.3; higher = more conserved; about 2 or more is strongly constrained coding sequence. Empty for unmapped rows. |
| `conservation_percentile` | Percentile rank (0-100) of `cds_phyloP_100way` among the mapped RBPs in this list; 100 = most conserved. |
| `conservation_tier` | `high` = top quarter (percentile >= 75), `low` = bottom quarter (<= 25), `medium` otherwise. Relative to this list, not an absolute threshold. Empty for unmapped rows. |
| `mouse_protein_identity_pct` | Percent of the human protein identical to the mouse ortholog (= `mmusculus_pid_query`). Empty if no mouse ortholog call. |
| `n_species_with_ortholog` | Number of the 10 species (chimpanzee to yeast) with an ortholog call. |
| `deepest_ortholog_species` | Most distant of those species with an ortholog call; `none` if no species has one. |
| `score_reliable` | True if the RBP is mapped, the scored isoform contains >= 90% of the input protein's residues, and >= 90% of CDS bases have alignment data. |
| `reliability_note` | Why `score_reliable` is False; empty when True. |
